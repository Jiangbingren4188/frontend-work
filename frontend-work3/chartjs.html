本页与 ECharts 页使用同一份数据，但换用 Chart.js 绘制，并选择与数据目的匹配的图表类型。数据通过 fetch 从本地 data/worlds.json 异步加载。

一、各世界人口规模对比（柱状图）

选型理由：回答"谁多谁少"用柱状图。纵轴从 0 开始，不夸大差异；人口单位为亿。

二、人口规模与税率的关系（散点图）

选型理由：回答"两个数值有没有关系"用散点图。横轴为人口（亿），纵轴为税率（%），每个点代表一个世界；豁免世界税率为 0，落在横轴上。

图表说明

图表库：Chart.js 4.5.1（本地 lib 离线包，UMD 版，画在 canvas 上）；数据来源：本地 JSON 文件；配置：responsive 响应式、纵轴 beginAtZero、图例置底。
